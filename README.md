# Organograma O Barracão

Página do organograma da equipe (setores, turnos, cargas horárias e salários).

Esta página **não guarda nenhum dado**. Nomes, horários e salários ficam na aba
**Equipe** da planilha "Estoque o Barracão" e só são lidos depois do login do
Painel DRE, por usuários com **Acesso total**.

Endereço: https://pontesgestao.github.io/organograma-o-barracao/
